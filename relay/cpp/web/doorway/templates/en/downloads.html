Cross-check against other relays

Compare this relay's file hashes against a random sample of other relays. If a majority disagree with this relay, don't trust this relay's downloads — get the files from a relay whose hashes match the majority.

Why bother with hash verification?

Any single relay could be compromised or malicious. If someone tampers with the binary on this relay, checking the hash on this same relay won't catch it — they can lie about the hash too. Cross-checking against other relays raises the bar: to fool you, an attacker would have to compromise a majority of the relays you sample from. This is not perfect but is much stronger than trusting any single source.
