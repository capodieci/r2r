Run your own relay {{hostToggleLabel}}
A relay is one small program (r2r-relay) — any always-on machine with an open TCP port works (a €3/month VPS is plenty). Every running relay redistributes its own binary and source on its /downloads page:
{{dlUrlLabel}}
Setup on a fresh Linux server — one command, run on the server
# log in to the server (SSH, root or sudo). Any relay's /downloads page has these files: curl -sSLO https://r2r.homes/assets/r2r-relay curl -sSLO https://r2r.homes/assets/install.sh curl -sSLO https://r2r.homes/assets/setup-tls.sh curl -sSLO https://r2r.homes/assets/r2r-relay.service chmod +x r2r-relay install.sh setup-tls.sh sudo ./install.sh YOUR-SERVER-IP:8787 # this server's own public IP (curl -4 ifconfig.me) # five invite codes were written on first start; mint more any time sudo cat /var/lib/r2r/genesis-invites.txt sudo r2r-relay --mint-invites 10 # make this wallet the relay's owner (paste the R2R_ address from Settings) — owner panel appears on next connect sudo r2r-relay --owner-add R2R_YOUR_ADDRESS
The installer creates the service user, a systemd unit, a self-signed certificate and the web site your relay serves at http://YOUR-SERVER-IP:8787/. Open TCP 8787 and 8788 in the firewall (and your provider’s cloud firewall). Then add ws://YOUR-SERVER-IP:8787 to Relays above (and onto your setup cards). No domain or TLS needed for a bare IP — everything is end-to-end encrypted anyway; TLS only hides traffic metadata. Want wss://? Point a domain at the server and run ./setup-tls.sh your.domain (free auto-renewing certificate). Sub-path installs like /R2R work — the wallet reads the relay’s base.
Per-account quotas, file lifetimes, invites and the storage market are managed live from the Relay owner panel above — changes apply instantly, no restart. Run ./r2r-relay --help for the full flag list (ports, TLS, advertise address, market pool), or open the relay's own /admin web console.
