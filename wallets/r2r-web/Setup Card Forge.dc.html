How it works
Each card carries a fresh random 256-bit card key and the relay address — no identity. The holder scans it in the wallet and chooses a PIN (at least 8 characters — an attacker holding the card key can grind short numeric PINs offline, so letters and length matter); card key + PIN derive where their encrypted identity lives on the relay. A photographed card is useless without the PIN, and there is nothing on it to brute-force offline.
Give each friend their own card. Use a clean, extension-free browser. Keep this forge file offline (USB stick) — it can re-download a card only while this page is open; a new key is minted on every load.
